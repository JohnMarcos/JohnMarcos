## 🏗️ What I've Built

### Fubenow

**EdTech · Marketplace · Multiplatform Product**

A platform designed to help creators and professionals transform their knowledge into digital products.

**Architecture**

```text
                ┌─────────────────────────┐
                │        Flutter          │
                │   iOS · Android · Web   │
                └────────────┬────────────┘
                             │
                          REST API
                             │
                ┌────────────▼────────────┐
                │     Ruby on Rails       │
                │      API Backend        │
                └────────────┬────────────┘
                             │
              ┌──────────────┼──────────────┐
              ▼              ▼              ▼
         PostgreSQL       Firebase      AI Services
```

The biggest engineering constraint was simple:

**How can one human developer build and maintain a multiplatform product without maintaining three independent applications?**

That constraint strongly influenced the architecture: a shared Flutter codebase, a centralized Rails backend, reusable services, automation, and extensive use of AI-assisted development.
